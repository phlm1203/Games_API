<h2>📖 Sobre este Repositório</h2>
<p>Este repositório contém o código-fonte de uma aplicação web moderna dedicada à navegação e descoberta de jogos online para PC, desenvolvida com integração direta a uma API pública de jogos. O objetivo é oferecer ao usuário uma experiência fluida e intuitiva para explorar, pesquisar e filtrar um vasto catálogo de títulos, com informações detalhadas sobre cada jogo disponibilizadas em tempo real via requisições à API.</p>
<p>A interface foi projetada com foco em usabilidade e design contemporâneo, permitindo que o usuário encontre rapidamente o que procura  seja por nome, data de lançamento, empresa desenvolvedora, gênero ou outras categorias relevantes — sem precisar sair da aplicação.</p>

<h2>
🕹️ Funcionalidades
</h2>

<ul>
<li><b>Busca por nome:</b> campo de pesquisa em tempo real que filtra os jogos conforme o usuário digita, consumindo o endpoint de busca da API</li>
<li><b>Filtro por data de lançamento:</b> permite ordenar ou restringir os resultados por período, do mais recente ao mais antigo e vice-versa</li>
<li><b>Filtro por desenvolvedora:</b> navegação por empresa responsável pelo desenvolvimento do jogo, facilitando a busca por títulos de um estúdio específico</li>
<li><b>Filtro por gênero e categoria:</b> segmentação dos jogos por tipo (ação, RPG, estratégia, FPS, etc.), com suporte a múltiplos filtros simultâneos</li>
<li><b>Visualização detalhada:</b> ao selecionar um jogo, o usuário acessa uma página ou modal com informações completas: descrição, capturas de tela, requisitos de sistema, avaliações e links relevantes, todos provenientes da API</li>
<li><b>Interface responsiva:</b> layout adaptado para diferentes tamanhos de tela, garantindo boa experiência tanto em desktops quanto em dispositivos móveis</li>
</ul>
